# AI-powered-assistant
### AI-Powered Natural Language Data Analytics Assistant

- **Technologies:** Python, Pandas, NumPy, SQL, SQLite, OpenAI API, Streamlit, Plotly, Scikit-learn
  - Developed an AI-powered analytics application to analyze CSV and Excel datasets using natural-language queries.
- Implemented data cleaning, preprocessing, and statistical analysis using Python and Pandas.
- Integrated an LLM to convert user questions into SQL queries for automated data analysis.
- Implemented SQL query validation and read-only execution to improve database security.
- Created interactive charts and data visualizations using Plotly to identify trends and patterns.
- Generated AI-powered insights from actual query results to support data-driven decision-making.
- Developed a Streamlit dashboard with dataset exploration, query history, and downloadable analysis reports.
